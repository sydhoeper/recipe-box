# Little Recipe Box

A phone-first recipe box with local recipe storage.

## Publishing
In repository Settings → Pages, deploy the main branch from /(root). Changes committed to main automatically publish.

## Data
Each browser keeps its own recipes. Clearing browser data removes them. Recipes do not sync across devices. The included default is Wild Rice and Mushroom Soup by Jamie Vespa, Dishing Out Health: https://dishingouthealth.com/wild-rice-mixed-mushroom-soup/

## Editing
Edit index.html, style.css, and app.js. No build step is needed. Increment the cache name in sw.js when releasing changes to the offline app.
